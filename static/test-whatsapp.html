🚀 Quick Start (Demo Mode)

The system works in demo mode without any credentials - messages will be logged to the console.

To send real WhatsApp messages, choose a provider and configure credentials:

Provider Options

1️⃣ Twilio (Easiest Setup)

  • Sign up: twilio.com/whatsapp
  • Get credentials: Account SID and Auth Token from console
  • WhatsApp number: Get a Twilio WhatsApp sender (starts with +14155238886 for testing)
  • Environment variables:
WHATSAPP_PROVIDER=twilio
TWILIO_ACCOUNT_SID=your_account_sid_here
TWILIO_AUTH_TOKEN=your_auth_token_here
TWILIO_WHATSAPP_NUMBER=+14155238886

Testing: Twilio Sandbox allows free testing without business verification

2️⃣ 360dialog (Template-focused)

  • Sign up: 360dialog.com
  • Get API key: From 360dialog Hub
  • Create templates: Templates must be approved by WhatsApp before use
  • Environment variables:
WHATSAPP_PROVIDER=360dialog
DIALOG360_API_KEY=your_api_key_here
DIALOG360_NAMESPACE=your_namespace_here

Best for: Businesses needing approved message templates

3️⃣ MessageBird (Omnichannel)

  • Sign up: messagebird.com/whatsapp
  • Get API key: From MessageBird Dashboard
  • Create channel: WhatsApp Business channel in Dashboard
  • Environment variables:
WHATSAPP_PROVIDER=messagebird
MESSAGEBIRD_API_KEY=your_api_key_here
MESSAGEBIRD_CHANNEL_ID=your_channel_id_here

Best for: Multi-channel messaging (SMS + WhatsApp + more)

📝 Business Verification

For production use, you need:

  • WhatsApp Business Account (register via provider)
  • Facebook Business Manager account
  • Business verification by Meta (2-5 business days)
  • Phone number verification (cannot be used with regular WhatsApp)
  • Template approval for pre-written messages

💰 Cost Breakdown

WhatsApp Business API is NOT free - here's what you need to budget:

📊 Message Pricing Details

Business-initiated conversations: $0.033 - $0.068 per conversation (24-hour window)

User-initiated conversations: Free for first response, then charged

Template messages: Lower cost, but must be pre-approved

Marketing messages: Higher cost (~$0.05-0.10 per message)

💡 Cost Optimization Tips

  • Use templates: Template messages cost less than freeform
  • 24-hour window: Multiple messages within 24 hours = one conversation charge
  • User-initiated: Respond to user messages for lower costs
  • Twilio Sandbox: Free for testing before going live
  • Alternative: Use WebPush (FREE) or Email (FREE) for notifications

🆓 Free Alternatives

If WhatsApp costs are too high, consider these FREE notification channels:

  • WebPush: Browser push notifications (100% free, works on all devices)
  • Email: Free tier with SendGrid, AWS SES, Mailgun
  • Android Push: Firebase Cloud Messaging (free, no subscription)

💰 Budget recommendation: Start with free channels, add WhatsApp when revenue justifies cost
